# THEEB Network Lab v4.0

لوحة عربية متقدمة لمراقبة معلومات الاتصال المتاحة داخل المتصفح وتشغيل **اختبار حمل شبكي متحكم به**.

## التشغيل
افتح `index.html` في متصفح حديث. لا توجد مكتبات أو عملية build مطلوبة.

## ماذا تقيس الصفحة؟
- حالة Online / Offline الحقيقية من المتصفح.
- Network Information API مثل `effectiveType` و`rtt` و`downlink` عندما يدعمها المتصفح.
- عدد محاولات الإرسال وحجم الـ payload ومعدل الحمل المحسوب من إعدادات الاختبار.
- رسم زمني للجلسة وسجل قابل للتصدير.

## مهم
هذه الصفحة ليست أداة سحرية لرفع سرعة اشتراك الإنترنت، وليست بديلًا كاملًا لـ Speedtest أو traceroute على مستوى النظام. تم حذف القياسات الوهمية الموجودة في النموذج السابق وعدم عرضها كأنها بيانات حقيقية.

## الأمان والاستهلاك
الحدود الافتراضية محافظة نسبيًا، لكن تشغيل مولد الحمل يستهلك بيانات فعلية. تجنب تشغيله طويلًا على باقات الجوال المحدودة.
